Lab 3 — GitHub Actions & YAML

Section 1 & 2: Moving to GitHub Actions

I opened my repository settings and went to the Pages section, where I unpublished the existing site and changed the source from GitHub Pages to GitHub Actions. I then navigated to the Actions tab, clicked "New Workflow", and selected "Set up a workflow yourself" to write a custom pipeline. Finally, I renamed the workflow file from main.yml to deployment.yml.

Section 3: Writing the YAML Pipeline

I wrote my deployment pipeline in YAML, starting with a name, then setting it to trigger on every push to the main branch. I added a job to spin up an Ubuntu VM, then wrote steps to check out the repository, set the required permissions, upload the files as an artifact, and finally deploy it to GitHub Pages.

How I Linked the Pages

I created a navigation bar at the top of both pages using HTML anchor tags. Each link uses the href attribute to point to the other page — index.html for the home page and lab3.html for this page. The active page is highlighted with a red left border so it's clear which page you're currently on. This approach keeps both pages consistent in style and easy to navigate between.
