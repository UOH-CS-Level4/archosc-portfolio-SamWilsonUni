Lab 4 — HTML, CSS and JS

Setting Up Files

I clicked the new file button in visual studio code and named one style.css and the other one script.js

These two lines in the HTML head and body link the page to its CSS and JavaScript files. Without them the page has no styling and none of the interactive features work. The link tag pulls in the stylesheet and the script tag at the bottom of the body loads the JavaScript after the page has fully loaded, which stops it from running before the elements exist.

Each lab needs its own separate HTML page because a single page would get too long and hard to navigate. Having individual files like lab1.html, lab2.html etc means you can link between them through the nav bar and keep each lab's screenshots and notes organised in one place. The folder structure shows all the files the site needs to work — the HTML pages, the shared style.css and script.js, and the Pictures folder where all the screenshots are stored

Home Page & CSS

It styles the portfolio's appearance, the animated gradient background, the card and entry layouts, and the nav bar. Without it the page would just be unstyled HTML with no colour, spacing or structure.

JavaScript Console

Nav Bar

I started with a basic list of links using an ordered list and anchor tags to connect the pages together. I then replaced this with a proper nav bar using a nav element with styled links that sit across the top of every page. Each link uses the href attribute to point to the relevant page, and the current page gets an active class which adds the red left border to show where you are. The nav bar is shared across all pages so you can move between them without using the browser back button.

Dark Mode

I added a button to the nav bar with an id of darkToggle so JavaScript could find it. In the CSS I created a body.dark class that overrides the background to plain black and removes the gradient animation, then added overrides for the entry and card colours too. In the JavaScript I added a click listener to the button that toggles the dark class on and off, and used localStorage to save the user's preference so it stays consistent when navigating between pages.
