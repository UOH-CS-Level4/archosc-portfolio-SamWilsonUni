Bonus Feature - Live Clock

00:00:00

This live clock updates every second using JavaScript's setInterval() function and the built-in Date object. It reads the current time from your device, formats the hours, minutes, and seconds with leading zeros using padStart(), and updates the page in real time without any page refresh.
