Lab Work

Reflection

Today I learned how to create a basic website using HTML and CSS, and how to use Git and GitHub to manage and publish my work. I started by writing a simple webpage that displayed my name, then improved it by changing the background to an animated gradient and adding a styled card around the text. I also learned how to use Git commands such as git init, git add, git commit, and git push to track changes and upload files to a GitHub repository. Finally, I deployed the website using GitHub Pages, which made it publicly accessible through a live link.

These skills are highly relevant in industry. Version control with Git is used by almost every software development team to collaborate on code, track changes, and avoid conflicts when multiple people are working on the same project. Knowing how to build and deploy websites is equally important, as businesses rely on web presence for everything from marketing to delivering products and services. Understanding how to make and push changes to a live site is a fundamental skill for any developer or web professional.
